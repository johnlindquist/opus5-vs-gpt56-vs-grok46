Before / after architecture

Legacy · one private pump

JobQueue owns pending array, active map, running count, drainers, and an inline #pump.
Priority via Array.sort on every add. Equal keys have no insertion sequence.
Retries mutate the same item and setTimeout with no handle. IDs are not unique.
drain watches pending length only. Cancel never settles the caller promise.

Replacement · owned state machine

types.ts public contracts · errors.ts typed failures · backoff.ts delay formula + default scheduler.
JobQueue holds live IDs, a pending list keyed by priority then sequence, in-flight occupancy, and cancellable retry handles.
stats() and subscribe() are observers. Listener throws are isolated.
Hooks inject delay and schedule so tests never sleep on exponential backoff.

State transitions

Occupancy (inFlight) includes a cancelled run until its function returns, so the concurrency ceiling stays honest. The ID is released at cancel so a new job may reuse it.
